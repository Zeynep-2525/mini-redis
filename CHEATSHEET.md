# Git Commands

## Status

```bash
git status
```

## Branches

```bash
git branch
git switch develop
git switch feature/hashmap
```

## Commit

```bash
git add .
git commit -m "message"
```

## Push

```bash
git push
```

## Pull

```bash
git pull
```

## History

```bash
git log --oneline --graph --all
```
