# Mini Redis

A simplified Redis implementation written in C.

## Goal

This project aims to understand how an in-memory key-value database works by implementing core Redis concepts from scratch.

## Planned Features

- [ ] Hash Table
- [ ] SET command
- [ ] GET command
- [ ] DEL command
- [ ] EXISTS command
- [ ] TCP Server
- [ ] Command Parser
- [ ] Client
- [ ] Persistence
- [ ] TTL
- [ ] Multiple Clients
